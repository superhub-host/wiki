Команда запуска — это команда, которую панель выполняет при нажатии кнопки «Запустить». Для обычной настройки достаточно доступных полей: имени исполняемого файла и аргументов JVM. Версия Java выбирается отдельно через образ Docker. Если нужна нестандартная команда, обратись в [техническую поддержку](/support).

## Где посмотреть команду

В панели Pterodactyl текущая команда находится во вкладке «Запуск»:

1. Открой [панель управления](https://panel.superhub.host).
2. Выбери нужный сервер.
3. Перейди во вкладку «Запуск».

В блоке «Команда запуска» показана готовая команда, а ниже — переменные, из которых она собирается. Например, поле «Исполняемый файл» может содержать `server.jar`, а поле «Аргументы JVM» — `-Xms128M -XX:MaxRAMPercentage=95.0`. Для такого набора команда выглядит так:

```sh
java -Xms128M -XX:MaxRAMPercentage=95.0 -jar server.jar
```

Пользователь меняет доступные переменные, а не сам шаблон команды. Набор полей зависит от выбранного ядра; поля с пометкой «Только чтение» редактировать здесь нельзя. Версию Java можно выбрать в блоке «Образ Docker» по [инструкции](/guides/minecraft/java-version).

## Аргументы JVM

Для Minecraft: Java Edition часто меняют не всю команду, а только аргументы JVM. Это параметры виртуальной машины Java: сборщик мусора, дополнительные флаги производительности и некоторые системные свойства. Подробнее о таких параметрах написано в отдельной статье: [«Добавить флаги запуска»](/guides/add-flags).

!> Не копируй случайные наборы флагов без проверки. Некоторые аргументы работают только на определённых версиях Java, а устаревшие параметры могут полностью сломать запуск.

### Генераторы команд

Иногда для Paper используют [Start Script Generator](https://docs.papermc.io/misc/tools/start-script-gen/). Он выдаёт целую команду запуска, которая начинается с `java`.

На хостинге обычно не нужно вставлять эту команду целиком. Если твоя задача — добавить оптимизационные флаги, скопируй только нужные JVM-аргументы, кроме параметров памяти, и укажи их в соответствующей переменной. Если вставить всю команду начиная с `java`, можно продублировать часть уже существующей команды запуска и сломать старт сервера.

Разберём сокращённый пример команды:

```sh
java -Xms2G -Xmx2G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -jar server.jar
```

Здесь `java` запускает Java, параметры до `-jar` относятся к JVM, `-jar server.jar` выбирает файл ядра. Если тебе нужны дополнительные флаги сборщика мусора, возьми из этого примера только `-XX:+UseG1GC -XX:+ParallelRefProcEnabled` и допиши их через пробел в конец поля «Аргументы JVM», сохранив существующие параметры. Например, если в поле уже было `-Xms128M -XX:MaxRAMPercentage=95.0`, получится:

```text
-Xms128M -XX:MaxRAMPercentage=95.0 -XX:+UseG1GC -XX:+ParallelRefProcEnabled
```

Не добавляй повторно флаги, которые уже есть в переменной. `java` и `-jar server.jar` в это поле не входят.

!> Параметры памяти уже заданы панелью: в примере выше это `-Xms128M -XX:MaxRAMPercentage=95.0`. Сохраняй исходные значения своего сервера и не заменяй всё поле набором из генератора. Не добавляй `-Xms2G -Xmx2G` из примера команды и не изменяй параметры памяти вручную: это может привести к некорректному выделению памяти серверу.

Сохрани изменения и перезапусти сервер.

## Файл запуска

Если ядро запускается через `-jar`, команда должна указывать на правильный `.jar`-файл. Например, если в корневой папке лежит файл `paper-1.20.4.jar`, а в переменной указано `server.jar`, сервер не сможет найти файл.

Есть два нормальных варианта:

- переименовать загруженный файл в `server.jar`;
- изменить переменную файла запуска на реальное имя, например
  `paper-1.20.4.jar`.

После изменения перезапусти сервер и проверь консоль. Если всё сделано верно, сервер начнёт загружать ядро, а не завершится сразу после старта.

### Forge и unix_args.txt

Шаблон Forge проверяет наличие `unix_args.txt` в корне сервера. Если файл есть, запуск идёт через `@unix_args.txt`, а значение поля «Исполняемый файл» не используется. Если файла нет, шаблон запускает `.jar`, указанный в этом поле. Поэтому для Forge с `unix_args.txt` изменение имени исполняемого файла не меняет способ запуска.

У NeoForge настроен запуск через `@unix_args.txt` без выбора между ним и `.jar`. Команда такого шаблона выглядит так:

```sh
java -Xms128M -XX:MaxRAMPercentage=95.0 -Dterminal.jline=false -Dterminal.ansi=true @unix_args.txt
```

Символ `@` означает, что Java читает параметры из файла. Это не `.jar`-файл: переименовывать его в `server.jar` или указывать после `-jar` нельзя.

Проверь, что `unix_args.txt` находится в корне сервера и загружена вся папка `libraries`, созданная установщиком. При ручной установке Forge скопируй файл аргументов своей версии из `libraries/net/minecraftforge/forge/` в корень по [инструкции](/guides/install-forge). Саму папку `libraries` сохраняй. Если нужных файлов нет, проверь результат установки; если требуется изменить шаблон команды, обратись в [поддержку](/support).

## Произвольная команда

Бывает такое, что какая-то сборка запускается через `.sh`-скрипт, использует нестандартный лаунчер, требует особую последовательность команд или не укладывается в обычные переменные панели. Изменять базовый шаблон команды напрямую пользователь обычно не может, поэтому напиши в [техническую поддержку](/support) точный текст итоговой желаемой команды, а также опиши, зачем нужна именно такая схема запуска.

## Распространённые ошибки

### Неверное имя файла

В консоли появляется ошибка:

```text
Error: Unable to access jarfile server.jar
```

Команда запуска ищет `server.jar`, но такого файла нет в корневой папке. Проверь имя файла, расширение `.jar` и регистр букв. На Linux `server.jar` и `Server.jar` — разные имена.

### Неподдерживаемый JVM-флаг

Сервер не запускается, а в консоли есть строки:

```text
Unrecognized VM option
Could not create the Java Virtual Machine
```

Обычно это значит, что в аргументах JVM есть опечатка или флаг, который не поддерживается выбранной версией Java. Удали последний добавленный параметр, сохрани изменения и перезапусти сервер.
