title: Изменение команды запуска
description: Как найти команду запуска сервера и изменить параметры старта.
---

Команда запуска — это команда, которую панель выполняет при нажатии кнопки «Запустить». Обычно полностью переписывать команду запуска не нужно. Чаще всего достаточно изменить одну из переменных: файл запуска, версию Java или аргументы JVM. Если нужна нестандартная команда, её лучше согласовать с [технической поддержкой](/support).

## Где посмотреть команду

Текущую команду запуска можно посмотреть в панели управления сервером.

1. Открой личный кабинет my.superhub.host.
2. Выбери нужный сервер.
3. Перейди во вкладку «Настройки».

В этом разделе обычно видно не только готовую команду, но и поля, из которых она собирается. Например, переменная с именем запускаемого файла может содержать `server.jar`, а переменная с аргументами JVM — параметры, которые будут подставлены после `java`.

## Аргументы JVM

Для Minecraft: Java Edition часто меняют не всю команду, а только аргументы JVM. Это параметры виртуальной машины Java: сборщик мусора, дополнительные флаги производительности и некоторые системные свойства. Подробнее о таких параметрах написано в отдельной статье:
[«Добавить флаги запуска»](/guides/add-flags).

!> Не копируй случайные наборы флагов без проверки. Некоторые аргументы работают только на определённых версиях Java, а устаревшие параметры могут полностью сломать запуск.

### Генераторы команд

Иногда для Paper используют [Start Script Generator](https://docs.papermc.io/misc/tools/start-script-gen/). Он выдаёт целую команду запуска, которая начинается с `java`.

На хостинге обычно не нужно вставлять эту команду целиком. Если твоя задача — добавить оптимизационные флаги, скопируй только JVM-аргументы и укажи их в соответствующей переменной. Если вставить всю команду начиная с `java`, можно продублировать часть уже существующей команды запуска и сломать старт сервера.

## Файл запуска

Если ты вручную загрузил новое ядро, команда запуска должна указывать на
правильный `.jar`-файл. Например, если в корневой папке лежит файл
`paper-1.20.4.jar`, а в переменной указано `server.jar`, сервер не сможет найти
файл.

Есть два нормальных варианта:

- переименовать загруженный файл в `server.jar`;
- изменить переменную файла запуска на реальное имя, например
  `paper-1.20.4.jar`.

После изменения перезапусти сервер и проверь консоль. Если всё сделано верно,
сервер начнёт загружать ядро, а не завершится сразу после старта.

## Произвольная команда

Бывает такое, что какая-то сборка запускается через `.sh`-скрипт, использует нестандартный лаунчер, требует особую последовательность команд или не укладывается в обычные переменные панели. Изменять базовый шаблон команды напрямую пользователь обычно не может, поэтому напиши в [техническую поддержку](/support) точный текст итоговой желаемой команды, а также опиши, зачем нужна именно такая схема запуска.

## Распространённые ошибки

### Неверное имя файла

В консоли появляется ошибка:

```text
Error: Unable to access jarfile server.jar
```

Команда запуска ищет `server.jar`, но такого файла нет в корневой папке. Проверь
имя файла, расширение `.jar` и регистр букв. На Linux `server.jar` и
`Server.jar` — разные имена.

### Неподдерживаемый JVM-флаг

Сервер не запускается, а в консоли есть строки:

```text
Unrecognized VM option
Could not create the Java Virtual Machine
```

Обычно это значит, что в аргументах JVM есть опечатка или флаг, который не
поддерживается выбранной версией Java. Удали последний добавленный параметр,
сохрани изменения и перезапусти сервер.
