Домен позволяет подключаться к серверу по понятному адресу вроде `play.example.com`, а не по набору цифр и порту. Для Minecraft он настраивается через DNS-записи: они объясняют игре, на какой IP-адрес и порт нужно подключаться через этот домен.

?> Если тебе нужен не свой купленный домен, а бесплатный адрес от Superhub формата `твоё_название.mineserver.xyz` или `твоё_название.my-craft.cc`, открой [эту инструкцию](/guides/minecraft/get-free-domain).

## Где взять домен

Домен можно купить у регистратора или получить как бесплатный поддомен. Для большого проекта лучше покупать собственный: он принадлежит тебе, его можно перенести между DNS-сервисами и использовать не только для сервера, но и для сайта, магазина или форума.

### Популярные регистраторы

Регистратор — это компания, через которую покупают домены. Подойдут почти любые, если они позволяют редактировать DNS-записи.

Популярные варианты:

- **Reg.ru** — российский регистратор с русскоязычной панелью и оплатой
  российскими картами.
- **Cloudflare Registrar** — зарубежный регистратор без большой наценки на
  продление, но не для всех зон и не для всех способов оплаты.
- **Beget** — русскоязычный хостинг и регистратор с простой панелью управления
  DNS.
- **Namecheap** и **Porkbun** — зарубежные регистраторы с большим выбором
  международных зон и демократичными ценами.

Перед покупкой проверь не только цену первого года, но и цену продления. У некоторых зон первый год стоит дёшево, а продление через год оказывается намного дороже.

### Бесплатные домены

Полностью бесплатные домены второго уровня сейчас встречаются редко, а многие старые сервисы либо закрылись, либо стали нестабильными. Часто под видом бесплатного домена дают поддомен вида `твоё_название.example.net`.

Для тестового сервера этого может хватить, но для публичного проекта лучше использовать домен, который ты контролируешь сам. Бесплатный адрес могут забрать, ограничить или заблокировать без удобного переноса.

### Домен от Superhub

На Superhub можно получить бесплатный поддомен для Minecraft сервера в зонах `*.mineserver.xyz` и `*.my-craft.cc`. Такой адрес удобно использовать, если ты не хочешь покупать отдельный домен, но хочешь дать игрокам понятный адрес для подключения.

Подробная инструкция находится здесь: [получение бесплатного домена](/guides/minecraft/get-free-domain).

## Доменная зона

Доменная зона — это окончание домена: `.com`, `.net`, `.org`, `.xyz`, `.ru`, `.рф`, `.su` и так далее. Технически Minecraft может работать почти с любой зоной, если DNS-записи настроены правильно.

Разница между зонами обычно в цене, доверии игроков, правилах регистрации и доступности из разных стран:

- международные зоны вроде `.com`, `.net`, `.org`, `.xyz` обычно подходят для любой аудитории;
- национальные зоны вроде `.ru`, `.рф`, `.su`, `.by` могут быть удобны для русскоязычного проекта, но хуже подходят для международной аудитории;
- необычные дешёвые зоны могут чаще попадать в антиспам-фильтры и выглядеть менее надёжно.

!> Домены в зонах `.ru`, `.рф`, `.su` и похожих национальных зонах могут быть недоступны или плохо открываться у части игроков вне России. Если сервер рассчитан на игроков из разных стран, безопаснее выбрать международную зону.

## Данные сервера

Перед настройкой DNS открой панель управления сервером и выпиши два значения:

- IP-адрес сервера без порта, например `185.9.145.215`;
- порт сервера, например `25615`.

Если адрес в панели выглядит как `185.9.145.215:25615`, то `185.9.145.215` — это IP-адрес, а `25615` — порт.

Для примеров ниже будем использовать:

- домен игрока — `example.com`;
- адрес для подключения — `play.example.com`;
- IP сервера — `185.9.145.215`;
- порт Java Edition сервера — `25615`;
- порт Bedrock Edition сервера — `25616`;
- регистратор — reg.ru.

Подставляй свои значения вместо этих примеров. Сразу замечу, что обновление записей в DNS у разных пользователей может занимать до нескольких суток.

## Java Edition

Minecraft: Java Edition умеет читать SRV-записи. Это позволяет игрокам вводить `play.example.com` без порта, даже если сервер работает не на стандартном порту `25565`.

Для Java Edition обычно нужны две записи:

- `A` запись — связывает домен или поддомен с IP-адресом сервера;
- `SRV` запись — говорит Minecraft, какой порт использовать.

![A-запись для Java Edition](/images/guides/minecraft/configure-domain/java-a-record.png)

На скриншоте показана A-запись для поддомена `play.example.com`. В поле `Subdomain` указано `play`, а в поле `IP Address` — IP-адрес сервера без порта.

Если ты хочешь использовать `example.com`, а не `play.example.com`, в поле `Subdomain` обычно нужно указать `@`.

![SRV-запись для Java Edition](/images/guides/minecraft/configure-domain/java-srv-record.png)

На скриншоте показана SRV-запись для подключения без порта. В поле `Service` указано `_minecraft._tcp.play`, порт равен `25615`, а `Target` указывает на `play.example.com`.

## Bedrock Edition

Minecraft: Bedrock Edition не использует SRV-записи при подключении к серверу. Для Bedrock обычно достаточно `A` записи:

![A-запись для Bedrock Edition](/images/guides/minecraft/configure-domain/bedrock-a-record.png)

На скриншоте показана A-запись для Bedrock-сервера: поддомен `bedrock.example.com` указывает на IP-адрес сервера. Порт для Bedrock всё равно нужно указать в игре отдельно, если он отличается от стандартного.

Игроки смогут указать адрес `bedrock.example.com` и порт `25616` для подключения.

## Cloudflare

Cloudflare удобно использовать как DNS-менеджер, даже если домен куплен у другого регистратора. Для этого домен добавляют в Cloudflare, а затем у регистратора заменяют NS-серверы на те, которые выдаст Cloudflare.

### A запись в Cloudflare

1. Открой Cloudflare Dashboard.
2. Выбери домен.
3. Перейди в раздел «DNS» → «Records».
4. Нажми «Add record».
5. Выбери тип `A`.
6. В поле «Name» введи `play`.
7. В поле «IPv4 address» введи IP сервера без порта.
8. Отключи проксирование: статус должен быть `DNS only`, серое облако.
9. Сохрани запись.

!> Оранжевое облако Cloudflare не подходит для обычного Minecraft трафика. Проксирование Cloudflare рассчитано на веб-сайты, а не на игровой протокол. Для Minecraft записи должны быть в режиме `DNS only`.

### SRV запись в Cloudflare

1. В том же разделе «DNS» → «Records» нажми «Add record».
2. Выбери тип `SRV`.
3. Заполни поля:
   - Service — `_minecraft`;
   - Protocol — `_tcp`;
   - Name — `play`;
   - Priority — `0`;
   - Weight — `5`;
   - Port — порт сервера из панели;
   - Target — `play.example.com`.
4. Сохрани запись.

После обновления DNS игроки смогут подключаться по адресу `play.example.com`.

## Проверка DNS

DNS может обновляться не сразу. Иногда запись уже работает у одного игрока, но ещё не работает у другого, потому что их провайдеры используют разные кеши DNS.

Для проверки `A` записи используй команду в терминале на своём устройстве (например, cmd на Windows):

```sh
nslookup play.example.com
```

или:

```sh
dig play.example.com A
```

Для проверки `SRV` записи Java Edition используй:

```sh
nslookup -type=SRV _minecraft._tcp.play.example.com
```

или:

```sh
dig _minecraft._tcp.play.example.com SRV
```

Корректный ответ SRV-записи выглядит примерно так:

```text
_minecraft._tcp.play.example.com. 300 IN SRV 0 5 25615 play.example.com.
```

Если нужно проверить домен из разных стран, используй онлайн-сервисы вроде `dnschecker.org`, `check-host.net`, `mcsrvstat.us` или `mcstatus.io`. Они помогут понять, обновились ли DNS-записи и отвечает ли Minecraft сервер на запросы.

## Распространённые проблемы

### DNS обновляется долго

После изменения NS-серверов или DNS-записей обновление может занять от нескольких минут до суток. В редких случаях делегирование домена обновляется дольше. Если ты только что поменял NS-серверы на Cloudflare, сначала дождись, пока Cloudflare покажет домен как активный.

### Нужен порт в Java Edition

Если игроки могут зайти по `play.example.com:25615`, но не могут зайти просто по `play.example.com`, проблема почти всегда в SRV-записи. Проверь имя `_minecraft._tcp.play`, порт и цель SRV-записи.

### Cloudflare включил прокси

Если `A` запись в Cloudflare отмечена оранжевым облаком, Minecraft может не подключиться. Переключи запись в режим `DNS only`.

### Bedrock не скрывает порт

Для Bedrock Edition это нормально — там всегда нужно указывать порт для подключения. SRV-запись используется только Java Edition и не решает эту проблему для Bedrock.
