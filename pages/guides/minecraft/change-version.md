Версию Minecraft можно изменить без удаления услуги. Если выбранная при покупке версия тебе не подошла или сервер не запускается, не спеши его перезаказывать, иначе можно потерять файлы, мир, настройки и уже оплаченный период. Сначала попробуй автоматическую или ручную установку. Новый же сервер нужен только в редких случаях, например, если ты хочешь перейти на другой тип услуги, допустим, с Minecraft на VPS.

!> Перед любыми действиями лучше сделать резервную копию. Новые версии Minecraft умеют обновлять миры, но старые почти никогда не могут безопасно открыть мир, который уже запускался на более новой версии.

## Установка при покупке

При заказе Minecraft сервера ты выбираешь версию из самых популярных вариантов, и хостинг автоматически устанавливает её. В таких случаях обычно после оплаты можно сразу открыть панель, запустить сервер и подключиться к нему по адресу из личного кабинета. Единственное возможное исключение — Forge: помимо версии игры там может понадобиться указать версию самого [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/), после чего переустановить сервер по кнопке в «Настройках».

## Автоматическая смена

Самый простой способ изменить версию или ядро — использовать встроенный установщик:

1. Открой [личный кабинет](https://my.superhub.host) и выбери нужную услугу.
2. Полностью останови сервер кнопкой «Стоп» во вкладке «Консоль».
3. Для смены версии укажи её в соответствующем поле, убедись, что все они заполнены, и переустанови сервер по красной кнопке внизу.
4. Для смены ядра нажми фиолетовую кнопку в самом низу «Настроек».
5. Проверь, что во вкладке «Файлы» появился `server.jar`. Если вместо этого есть лишь, условно, `forge-26.1.2-64.0.9-shim.jar`, нужно указать это название во вкладке «Настройки» в поле «Исполняемый файл» (как при ручной установке).
6. Включи сервер и проверь консоль. В случае понижения версии может понадобиться удалить старую папку мира (обычно это «world»).

![Поля версии Minecraft, типа сборки и версии Forge](/images/guides/minecraft/change-version/version-settings.png)

На скриншоте показаны переменные во вкладке «Настройки»: версия Minecraft, тип сборки Forge и точная версия Forge. Если меняешь Forge-сервер, проверь все эти поля перед переустановкой.

## Ручная смена

Ручная установка нужна, если в панели нет нужного билда, требуется редкая версия и т.д. В этом варианте ты сам скачиваешь файл ядра и загружаешь его в корень сервера:

1. Останови сервер во вкладке «Консоль» панели управления сервером.
2. Скачай нужное ядро только с официального сайта проекта (ссылки для скачивания ниже).
3. Открой вкладку «Файлы» или подключись к серверу через [SFTP](/guides/use-sftp).
4. Загрузи новый `.jar`-файл в корневую папку сервера.
5. Укажи название загруженного файла во вкладке «Настройки» сервера в личном кабинете.

![Поле «Исполняемый файл» в настройках сервера](/images/guides/minecraft/change-version/jar-file-setting.png)

В поле «Исполняемый файл» должно быть указано точное название `.jar`-файла, который лежит в корне сервера. Если файл называется не `server.jar`, впиши его реальное имя.

## Forge и NeoForge

Forge и NeoForge устанавливаются не так, как Paper или Purpur. Обычно у них есть
инсталлятор, папка `libraries`, дополнительные файлы запуска и свои требования к
версии Java. Если просто заменить `server.jar` на файл инсталлятора, сервер может
не запуститься. Для таких случаев используй [отдельную инструкцию](/guides/install-forge).

## Версия Java

Разным версиям Minecraft нужна разная Java. Если версия Java не подходит, сервер
может завершиться сразу после запуска.

Частый пример ошибки:

```text
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled by a more recent version of the Java Runtime
```

Эта ошибка означает, что ядро собрано под более новую Java, чем та, которая
выбрана на сервере. Например, старые версии Minecraft часто запускаются на Java
8, версии 1.18–1.20.4 обычно требуют Java 17, а версии 1.20.5 и новее — Java
21.

Изменить Java можно по инструкции
[«Выбор и смена версии Java»](/guides/minecraft/java-version).

## Распространённые ошибки

### Сервер не видит файл

В консоли появляется ошибка:

```text
Error: Unable to access jarfile server.jar
```

Команда запуска ищет файл `server.jar`, но такого файла нет в корневой папке.
Проверь имя файла, расширение `.jar` и регистр букв. Для Linux имена
`server.jar` и `Server.jar` считаются разными.

### Мир от новой версии

После отката версии в логах может появиться сообщение:

```text
Server attempted to load chunk saved with newer version of minecraft
```

Это значит, что сервер пытается открыть мир, который уже сохранялся на более
новой версии Minecraft. Надёжное решение — вернуть прежнюю версию сервера,
восстановить бэкап или удалить папки мира (`world`, `world_nether`,
`world_the_end`) и сгенерировать карту заново.

### Не подходят моды

Если сервер запускается, но падает при загрузке модов, проверь версии модов,
загрузчика и Minecraft. Например, Fabric-мод для `1.20.1` не обязан работать на
`1.20.4`, а Forge-мод нельзя просто перенести на NeoForge без проверки
совместимости.

### Не работает команда version

На Paper, Purpur, Spigot и похожих ядрах можно проверить версию командой
`version` в консоли. На Vanilla, Forge и Fabric такой команды может не быть. В
этом случае смотри первые строки запуска в консоли или файл `logs/latest.log`.
