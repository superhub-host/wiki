Данная услуга помогает дать игрокам понятный адрес сервера без покупки собственного домена. Вместо IP с портом можно использовать поддомен в одной из зон Superhub: `*.mineserver.xyz` или `*.my-craft.cc`. Если же тебе нужен полностью свой домен вроде `example.com`, купи его у регистратора и настрой по [этой инструкции](/guides/minecraft/configure-domain).

## Особенности

Бесплатный домен доступен для платных серверов. Ты получаешь поддомен в общей зоне Superhub, например `wintercraft.mineserver.xyz`, а не отдельный домен второго уровня.

?> Для адреса в другой зоне, например `wintercraft.ru` или `wintercraft.com`, нужно приобрести собственный домен. Бесплатная функция не выдаёт домены в произвольных зонах.

## Java и Bedrock

Для Minecraft: Java Edition бесплатный домен может использовать SRV-запись. Это позволяет игрокам подключаться по адресу без ручного ввода порта.

Для Minecraft: Bedrock Edition ситуация другая. Bedrock не поддерживает SRV при подключении к серверу, поэтому домен может указывать на IP-адрес, но нестандартный порт всё равно придётся вводить в игре отдельно.

## Получение домена

1. Авторизуйся на [my.superhub.host](https://my.superhub.host) и выбери платный Minecraft сервер.
2. Перейди во вкладку «Домены» и нажми «Создать домен».
3. Выбери тип: для Java Edition — «SRV запись», чтобы подключаться без порта; для Bedrock Edition — «A запись», чтобы домен указывал на IP. A-запись не хранит порт: его нужно указать отдельно в игре. В форме также есть «CNAME запись для TCPShield» — она нужна только при настройке этого сервиса и требует выданного им значения CNAME.
4. Введи имя строчными латинскими буквами, цифрами и дефисами, например `wintercraft`, и выбери зону `my-craft.cc` или `mineserver.xyz`.
5. Нажми «Продолжить», проверь тип записи, полный домен и сервер, затем подтверди создание.
6. Дождись обновления DNS и проверь подключение по новому адресу.

Лимит доменов отображается в кабинете. Если он достигнут, кнопка создания недоступна. На бесплатном тарифе поддомен Superhub недоступен, но можно подключить собственный домен через DNS у его провайдера.

?> Если имя уже занято другим сервером, выбери другой вариант. Например, вместо `survival` можно попробовать `survivalmc`, `survival2026` или название своего проекта.

## Проверка

Проверяй запись того типа, который выбрал при создании домена. Ниже приведены условные примеры ответов: у тебя будут свои имя, IP-адрес и порт.

### Проверка A-записи

Если выбрал A-запись, выполни команду в терминале на своём устройстве (например, cmd на Windows):

```sh
nslookup wintercraft.mineserver.xyz
```

Пример успешного ответа:

```text
Server:  one.one.one.one
Address:  1.1.1.1

Non-authoritative answer:
Name:    wintercraft.mineserver.xyz
Address: 185.9.145.215
```

Первые строки `Server` и `Address` показывают DNS-сервер, который отвечает на запрос. Адрес Minecraft-сервера находится ниже, после имени `wintercraft.mineserver.xyz`. Именно его нужно сравнить с IP в личном кабинете.

### Проверка SRV-записи

Для Java Edition с типом SRV выполни:

```sh
nslookup -type=SRV _minecraft._tcp.wintercraft.mineserver.xyz
```

Пример успешного ответа:

```text
Server:  one.one.one.one
Address:  1.1.1.1

Non-authoritative answer:
_minecraft._tcp.wintercraft.mineserver.xyz SRV service location:
          priority       = 0
          weight         = 5
          port           = 25615
          svr hostname   = node.example.net
```

В ответе должны быть игровой порт (`port`) и целевое имя сервера (`svr hostname`, иногда называется `target`). В этом примере порт — `25615`, а целевое имя — условное `node.example.net`. Проверь имя из своего ответа отдельной командой:

```sh
nslookup node.example.net
```

Полученный IP-адрес и порт из SRV-ответа должны совпадать с адресом сервера в панели. При типе SRV обычный запрос `nslookup wintercraft.mineserver.xyz` сам по себе не проверяет игровой адрес: IP нужно узнавать именно у цели SRV-записи.

### Запись не найдена

Неуспешный ответ может выглядеть так:

```text
Server:  one.one.one.one
Address:  1.1.1.1

** server can't find _minecraft._tcp.wintercraft.mineserver.xyz: NXDOMAIN
```

`NXDOMAIN` или `Non-existent domain` означает, что запрошенное имя не найдено. Адрес `1.1.1.1` в начале ответа принадлежит DNS-серверу и не подтверждает, что домен настроен. Сообщение `No answer` также не подтверждает наличие нужной записи. Проверь написание имени и выбранный тип записи, подожди обновления DNS и повтори запрос.

Также можно использовать онлайн-проверки: `dnschecker.org`, `check-host.net`, `mcsrvstat.us` или `mcstatus.io`.

## После смены основного порта

Не рассчитывай на автоматическое обновление бесплатной SRV-записи после смены основного порта. Открой «Домены» и сравни порт записи с новым основным портом, затем проверь результат через `nslookup -type=SRV`, как показано выше. Если запись осталась прежней, обратись в [поддержку](/support): ручное редактирование DNS в этой форме недоступно. Пока запись не исправлена, подключайся по IP и новому порту.

## Распространённые проблемы

### DNS обновляется долго

Иногда домен начинает работать не сразу. DNS-кеш может храниться на стороне провайдера, роутера или устройства игрока. Обычно достаточно подождать от 15 минут до нескольких часов.

Если прошло больше суток, проверь, что сервер активен, домен сохранён в панели и добавлен в игре без опечаток. Если всё верно, а домен не работает, напиши в [техническую поддержку](/support): укажи домен, ID сервера и приложи результат проверки `nslookup`.

### Нужно вводить порт

Для Java Edition порт обычно скрывается через SRV-запись. Если игрокам всё равно приходится вводить порт, подожди обновления DNS и проверь SRV-запись.

Для Bedrock Edition это ожидаемое поведение, игрокам нужно указать домен в поле адреса, а порт — в отдельном поле порта.

### Имя занято

Бесплатные домены выдаются в общих зонах, поэтому короткие красивые имена могут быть уже заняты. Добавь к названию проекта короткую приставку, год, режим игры или регион, но не делай адрес слишком длинным: помни, что именно игрокам придётся вводить его.
