---

Данная услуга помогает дать игрокам понятный адрес сервера без покупки собственного домена. Вместо IP с портом можно использовать поддомен в одной из зон Superhub: `*.mineserver.xyz` или `*.my-craft.cc`. Если же тебе нужен полностью свой домен вроде `example.com`, купи его у регистратора и настрой по [этой инструкции](/guides/minecraft/configure-domain).

## Особенности

1. Это не отдельный домен второго уровня, а поддомен в зоне Superhub. Его можно использовать только для подключения к серверу, а доменная зона останется общей, и без вашей приставки будет просто открываться наш сайт.

?> Для использования других зон, например `.com`, `.net`, `.org`, `.ru` или `.xyz`, нужно купить собственный домен у регистратора. Бесплатная функция не выдаёт домены в произвольных зонах.

2. Бесплатный домен доступен только для платных серверов.

## Java и Bedrock

Для Minecraft: Java Edition бесплатный домен может использовать SRV-запись. Это позволяет игрокам подключаться по адресу без ручного ввода порта.

Для Minecraft: Bedrock Edition ситуация другая. Bedrock не поддерживает SRV при подключении к серверу, поэтому домен может указывать на IP-адрес, но нестандартный порт всё равно придётся вводить в игре отдельно.

## Получение домена

Порядок действий может немного отличаться в зависимости от текущего интерфейса личного кабинета, но общая логика такая:

1. Авторизуйся на [my.superhub.host](https://my.superhub.host).
2. Выбери нужный Minecraft сервер.
3. Перейди во вкладку «Домены» и нажми «Создать домен».
4. Введи желаемое имя без точки и доменной зоны, например `wintercraft`.
5. Выбери одну из доступных зон: `mineserver.xyz` или `my-craft.cc`.
6. Сохрани изменения.
7. Подожди обновления DNS и попробуй подключиться к серверу по новому адресу.

?> Если имя уже занято другим сервером, выбери другой вариант. Например, вместо `survival` можно попробовать `survivalmc`, `survival2026` или название своего проекта.

## Проверка

После сохранения домена проверь, что его видно. Для этого можно использовать команду в терминале на твоём устройстве (например, cmd на Windows):

```sh
nslookup wintercraft.mineserver.xyz
```

Для Java Edition можно дополнительно проверить SRV-запись:

```sh
nslookup -type=SRV _minecraft._tcp.wintercraft.mineserver.xyz
```

Если команды возвращают IP-адрес и порт сервера, DNS-записи уже применились. Если ответа нет, подожди и повтори проверку позже.

Также можно использовать онлайн-проверки: `dnschecker.org`, `check-host.net`, `mcsrvstat.us` или `mcstatus.io`.

## Распространённые проблемы

### DNS обновляется долго

Иногда домен начинает работать не сразу. DNS-кеш может храниться на стороне провайдера, роутера или устройства игрока. Обычно достаточно подождать от 15 минут до нескольких часов.

Если прошло больше суток, проверь, что сервер активен, домен сохранён в панели и добавлен в игре без опечаток.

### Нужно вводить порт

Для Java Edition порт обычно скрывается через SRV-запись. Если игрокам всё равно приходится вводить порт, подожди обновления DNS и проверь SRV-запись.

Для Bedrock Edition это ожидаемое поведение, игрокам нужно указать домен в поле адреса, а порт — в отдельном поле порта.

### Имя занято

Бесплатные домены выдаются в общих зонах, поэтому короткие красивые имена могут быть уже заняты. Добавь к названию проекта короткую приставку, год, режим игры или регион, но не делай адрес слишком длинным: помни, что именно игрокам придётся вводить его.
